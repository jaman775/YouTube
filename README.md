# Drishyopot

Independent Android video client. Written from scratch (Kotlin + Jetpack Compose).

## Build
1. Open this folder in **Android Studio** (Ladybug 2024.2 or newer, JDK 17).
2. Let Gradle sync. If `gradlew` is missing, Android Studio uses the settings in
   `gradle/wrapper/gradle-wrapper.properties`; or run `gradle wrapper` once.
3. Run the `app` configuration on a device/emulator with Android 6.0+ (API 23).

## Build with GitHub (no Android Studio needed)
1. Create a repository, upload this folder's contents, push to `main`.
2. Open **Actions → Build APK**. When it is green, download **Drishyopot-debug-apk** from the run's Artifacts and install it.
3. Optional signed release APK: add these repository secrets (Settings → Secrets and variables → Actions):
   `ANDROID_KEYSTORE_BASE64` (`base64 -w0 my.jks`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
   Pushing a tag like `v0.1.0` then publishes a GitHub Release with the APK.

## Player settings and voice search
- The player's gear icon opens a YouTube-style sheet (Quality, Playback speed, Captions, Audio track, Lock screen, More →
  Loop video, Ambient mode, Stable volume, Sleep timer, Help & feedback): `ui/player/PlayerSettingsSheet.kt`.
- YouTube's own microphone button works in the browser tab: `assets/browser/speech.js` provides `webkitSpeechRecognition`
  on top of Android's recogniser (`browser/WebSpeechBridge.kt`). The first use asks for the microphone permission.

## SponsorBlock note
SponsorBlock segments are keyed by YouTube video ID. Until the YouTube resolver (Phase 6) exists,
enter the 11-character video ID in the optional field on the Home screen to test skipping on a
direct media URL of the same video.

## YouTube support (Phase 6) – read this first
- Stream resolving uses **NewPipe Extractor** (GPLv3), pulled from JitPack and wrapped in the `engine`
  module. The version is pinned in `gradle/libs.versions.toml` (`newpipe`, currently v0.26.5), but the
  engine can also be **updated online without a new APK** — see `OTA.md`. Because the extractor is GPLv3,
  the combined app must be distributed under GPLv3 too.
- Blocking ads and downloading/streaming outside YouTube's own apps goes against YouTube's Terms of Service.
  Do not publish this build on Google Play.
- Video links open in the native player; everything else (home, search, channels, sign-in) is browsed in
  the WebView with ads stripped (`app/src/main/assets/browser/inject.js`).
- **PO tokens** are generated by running YouTube's BotGuard challenge in a hidden WebView
  (`tools/potoken`, built on bgutils-js, MIT) and handed to the extractor. **Cookies**: signing in through
  the browser tab (Settings → YouTube account) lets the engine and downloader use your account for
  age-restricted and members-only videos; cookies are only sent to youtube.com.

## Casting (Phase 7)
- Discovery uses mDNS (`_googlecast._tcp`); the session speaks Cast V2 over TLS to the Default Media Receiver.
- **Device certificates are not verified** (Google's device CA is not bundled). Use on trusted networks only.
- The phone runs a small HTTP proxy (`LocalStreamProxy`) so the TV never talks to YouTube directly.
  It tries a DASH manifest (H.264 + AAC, up to 1080p) first and falls back to a single combined file if the
  receiver rejects it.
- "Open on any device" serves a player page from the proxy to any browser on the same Wi-Fi. When only
  separate streams exist, that page loads dash.js 4.7.4 from cdnjs, so the other device needs internet.
- This has not been tested against real hardware. Check the diagnostic log (About → Save diagnostic logs,
  lines tagged `Cast`) if a device connects but does not play.

## Downloads (Phase 5)
- Files are fetched as 4 MiB blocks over 1–8 connections (Settings → Downloads); finished blocks are saved,
  so pause/resume and crashes lose at most a few blocks.
- Video + audio are joined with Android's `MediaMuxer` (no re-encoding): H.264/HEVC + AAC → `.mp4`,
  VP9/AV1 + Opus → `.webm`. Audio-only saves `.m4a` (or `.webm` for Opus). The result is checked
  (tracks present, duration within tolerance) before it is moved to Movies/Drishyopot or Music/Drishyopot.
  Subtitles and cover images go to Download/Drishyopot.
- Before Android 10 files are saved in the app's own external folder (no storage permission needed).
- Downloads wait when offline or, with "Wi-Fi only", on a metered network, and continue automatically.
- Playlists: up to 500 videos per batch; the options dialog applies one setting set to all of them.
- Update check: set `resValue("string", "update_repo", "owner/repo")` in `app/build.gradle.kts` to show
  "Check for updates" in About (uses that repository's latest GitHub release).

## Known gaps
- Translations: English and Bengali only. Add more with `app/src/main/res/values-<code>/strings.xml`.
- The PO-token flow follows bgutils-js and is tested against a fake BotGuard VM only; Google can change
  the challenge at any time (the PO-token page is itself updatable online, see OTA.md).
- Nothing here has been compiled or run on a device by the author: expect a few fixes on first build.

## Tests
- `./gradlew test` – Kotlin and Java unit tests.
- `cd tools/potoken && npm install && npm test` – PO-token glue against a fake BotGuard VM.

## How the app is laid out
- It opens straight into YouTube, full screen, with no app bar.
- The app's own menu (voice search, address/search, tabs, open a link, settings, downloads, queue,
  account, engine and updates, about, copy/share/open elsewhere) is injected into YouTube's **You**
  page by `app/src/main/assets/browser/inject.js`. If YouTube ever changes that page, the menu can be
  fixed by an online update of that script (see OTA.md); until then the same screens are reachable from the
  launcher icon's long-press shortcuts (Downloads, Settings, YouTube account, Engine) and from the
  error page shown when YouTube cannot be loaded.
- No emoji are used as icons anywhere; icons are Material vectors (and inline SVG in the page menu).
- `cd tools/page-script && npm install && npm test` checks the page script against a simulated YouTube page.
